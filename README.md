# Redis Chat на Python + Docker

Мини-чат на FastAPI с Redis Pub/Sub. Сообщения публикуются в Redis и рассылаются подключённым браузерам. Есть имя пользователя, системные ответы сервера и функция «Ответить» на сообщение.

## Запуск

1. Установите и запустите Docker Desktop.
2. Распакуйте архив и откройте терминал в папке проекта.
3. Соберите и запустите контейнеры:

   ```bash
   docker compose up --build
   ```

4. Откройте http://localhost:8000
5. Откройте этот адрес в двух вкладках/браузерах и отправьте сообщения для проверки чата.

## Проверка

- Страница чата: http://localhost:8000
- Проверка сервера и Redis: http://localhost:8000/health
- В терминале логи: `docker compose logs -f`
- Остановка: `Ctrl+C`, затем `docker compose down`
- Повторная сборка после изменений: `docker compose up --build`

## Как это работает

- `main.py` — Python-сервер FastAPI и WebSocket-соединения.
- Redis Pub/Sub (`chat:messages`) — брокер сообщений.
- `static/` — интерфейс чата.
- `Dockerfile` — сборка контейнера приложения.
- `docker-compose.yml` — запуск приложения и Redis в одной сети Docker.

Важно: Redis Pub/Sub рассылает сообщения только активным подписчикам; история чата в этом учебном проекте не сохраняется. Не используйте его как production-чат без аутентификации, защиты от злоупотреблений и хранения истории.
